## Требования

Цель: Знакомство с PHP

1. Скачать и установить сборку сервера http://open-server.ru/ либо другую подходящую (http://www.apachefriends.org/ru/xampp.html, http://www.denwer.ru/ и др)
2. По методичке PHP1.pdf выполнять задания (в mysite.local)
-	синтаксис PHP, операторы,переменные,константы в PHP
-	вывод информации
-	функции в PHP (Вывод даты и д.)
-	типы данных и операции с ними
-	управляющие конструкции  if,  if-elseif-else
-	конструкция switch
-	операции с массивами
-	циклы: for, while, do-while, foreach
-	конструирование сайта
-	создание динамического навигационного меню
-	работа с формами, передача данных от пользователя
-	создание калькулятора
-	создание динамической таблицы умножения

## Технологии

- HTML5
- CSS
- PHP 7.2

## Установка и запуск

1. Клонируйте репозиторий

```bash
git clone https://github.com/Archive-of-practical-work-for-the-PRUE/Website-Development-On-Bitrex.git -b php
```

2. Откройте терминал

3. Запустите команду `docker compose up`

4. Откройте http://localhost:8000
